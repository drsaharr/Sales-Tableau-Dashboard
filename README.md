TableauDashboard


An interactive Tableau dashboard built to analyze sales performance, revenue distribution, and customer trends.  
This project transforms raw sales data into clear business insights that support better decision-making.

## Key Highlights
- Analyzed revenue by region, product category, gender, and age group
- Designed interactive visuals to uncover sales patterns and customer behavior
- Built a clean, structured dashboard layout for executive-level reporting
- Applied data visualization best practices to improve readability and insight delivery
